## Entry points

Run these commands from the repository root, after installing the appropriate dependencies:

| Workflow | Command |
|---|---|
| General desktop application | `python app.py` |
| Compact-tension desktop application | `python ct_app.py` |
| Included real-image example | `python examples/lab_demo.py --output demo_output/lab` |

The desktop interface is primarily Hebrew; the documentation and example figures are in English.
